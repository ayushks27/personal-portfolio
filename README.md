# Personal Portfolio

A modern portfolio website showcasing my work, projects, and technical skills.

* Showcases my projects, technical skills, and professional experience.
* Features a modern, responsive, and interactive user interface.
* Built using React, TypeScript, Tailwind CSS, and Framer Motion.
* Highlights featured projects, research work, and technical blogs.
* Includes smooth animations and engaging user interactions.
* Designed with a focus on performance, accessibility, and scalability.
* Serves as a central hub for my portfolio, achievements, and contact information.
* Demonstrates my passion for building intuitive and visually appealing web applications.
